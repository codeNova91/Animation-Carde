# Animation-Carde
Projet : Modern Animated Card
​Description :
​Un composant d'interface utilisateur (UI) moderne mettant en œuvre des effets visuels avancés en CSS3. Ce projet explore l'utilisation des dégradés animés (Gradients), des ombres portées (Box-shadows) et des transitions fluides pour créer une carte interactive élégante.
​Technologies utilisées :
​HTML5.
​CSS3 Animations.
